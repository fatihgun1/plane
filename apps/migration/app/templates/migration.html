Jira → Plane Migration

Fetch tasks from Jira with the configured connection, map statuses, and push them into a Plane project in batches.

1 · Target

Each migration targets one Plane project — you can use several. Pick an existing project, click Use Jira project to mirror your Jira project (same name & key), or + New project to create a fresh one in Plane.

2 · Preview from Jira

This is a sample to check your JQL and map statuses — the migration ingests ALL issues matching the JQL (no row cap), in batches. Click the JQL field to pick a ready-made query.

Users in this sample

Selected assignees are invited to your Plane workspace via Plane's own invitation flow (role: Member). They become assignable once they accept the invite. Already-members are skipped.

3 · Status mapping

Map each Jira status to a Plane state. "Create" adds a new state to the project with the suggested group.

Jira statusCategoryPlane state

4 · Push to Plane

Plane API limit is 60 req/min — large selections take a while (~1 item/sec).

Confluence Connection

Confluence uses the same Atlassian email + API token as your Jira Connection. Set the wiki base URL and the space to migrate. Base URL defaults to your Jira site + /wiki.

1 · Target

Migrates a Confluence space's pages into the selected Plane project — page hierarchy (sub-pages) and internal page links are preserved; content is converted to Plane's format.
